# Тест на стенді перед монтажем

Мета: перевірити всі модулі (живлення, Wi-Fi, MQTT/API, Bluetooth BMS, OTA) перед встановленням на віддаленому об'єкті.

## Підготовка
- [ ] Канал зв'язку працює (локальний API або MQTT міст: `tools/mqtt-sub.sh 'victor/bridge/state' 10` → `1`)
- [ ] `secrets.yaml` заповнено
- [ ] MINI-360 виставлено рівно на 5.0 В
- [ ] Антена підключена до ESP32 (якщо використовується ESP32U)
- [ ] BMS вільна для підключення (приймає одне BLE-з'єднання)

## Перевірки
1. [ ] **Прошивка:** `tools/build.sh victor-pi30.yaml` (або `victor.yaml`), прошити по USB.
2. [ ] **Wi-Fi і світлодіод:** без кабелю інвертора, живлення від USB. Світлодіод: швидке блимання → повільне → горить постійно.
3. [ ] **Зв'язок з HA:** в HA з'явився пристрій **Victor** у зоні «СЕС», сенсори оновлюються.
4. [ ] **Живлення від інвертора:** підключити новий блок у RJ45 інвертора, USB вийняти. Блок живиться від порту інвертора.
5. [ ] **Дані інвертора:** сенсори потужності PV, навантаження, напруги батареї збігаються з дисплеєм інвертора.
6. [ ] **Керування:** змінити струм заряду чи режим у Home Assistant — нове значення відображається на дисплеї інвертора.
7. [ ] **BMS:** `binary_sensor.victor_bms_online_status` = on, SOC і комірки збігаються з даними акумулятора.
8. [ ] **Вибір BMS з HA:** у `sensor.victor_bms_found_devices` видно знайдені Bluetooth BMS. Вписати MAC-адресу у `text.victor_bms_mac` → блок перепідключається до вказаного акумулятора.
9. [ ] **Точка доступу Captive Portal:** тимчасово вимкнути Wi-Fi роутер (або прошити з тестовим SSID). Через ~1 хв з'являється мережа «Victor Setup», смартфон відкриває сторінку вибору Wi-Fi для підключення.
10. [ ] **Стійкість до збоїв:** вимкнути роутер на 20 хв → після відновлення зв'язок відновлюється автоматично. При перезавантаженні лічильники енергії зберігають значення.
11. [ ] **OTA оновлення:** перевірено локальне або віддалене OTA оновлення.
12. [ ] **Веб-інтерфейс:** доступний за локальною IP-адресою у браузері.

## Перед відправкою на об'єкт
1. [ ] Скомпілювати та прошити робочу конфігурацію (`victor.yaml` чи згенеровану через `tools/constructor.py`).
2. [ ] Блок успішно підключається, BMS онлайн.
3. [ ] У `secrets.yaml` вказано Wi-Fi віддаленого об'єкта (або підключення буде виконано на місці через Captive Portal).
4. [ ] Роздрукувати або переслати [інструкцію для людини на місці](onsite-uk.md).
