# Тест вдома на SP-3200 (до відправки)

Мета: перевірити все, крім розмови з Victor (у нього Modbus, у SP-3200 — PI30).
Під час тесту домашній Solar2MQTT від'єднано, тож `ecgsolax_*` в HA будуть недоступні.

## Підготовка
- [ ] Міст працює: `tools/mqtt-sub.sh 'victor/bridge/state' 10` → `1` ([bridge.md](bridge.md))
- [ ] `secrets.yaml` заповнено, `flespi_token` = токен `victor-node`
- [ ] MINI-360 виставлено на 5.0 В
- [ ] Антена прикручена до ESP32U
- [ ] В HA вимкнено `switch.jk_bms_gateway_battery_7700wh_ble_connection` (JK приймає одне BLE-з'єднання)

## Перевірки
1. [ ] **Прошивка:** `tools/build.sh victor-pi30.yaml`, прошити по USB.
2. [ ] **Wi-Fi і світлодіод:** без кабелю інвертора, живлення від USB. Світлодіод: швидке блимання → повільне → горить постійно.
3. [ ] **Хмара → HA:** в HA з'явився пристрій **Victor** у зоні «Дача», сенсори оновлюються.
4. [ ] **Живлення від інвертора:** від'єднати Solar2MQTT, вставити новий блок у RJ45 SP-3200, USB вийняти. Блок працює.
5. [ ] **Дані інвертора:** `sensor.victor_pv_power`, `sensor.victor_load_power`, `sensor.victor_battery_voltage`, `sensor.victor_working_state` збігаються з дисплеєм.
6. [ ] **Команда:** змінити `number.victor_utility_charge_current` (наприклад 20 → 30). Нове значення видно на дисплеї інвертора (меню 11).
7. [ ] **BMS:** `binary_sensor.victor_bms_online_status` = on, SOC і комірки збігаються з застосунком JK.
8. [ ] **Вибір BMS з HA:** у `sensor.victor_bms_found_devices` видно домашні JK. Вписати MAC другої батареї (`C8:47:80:1B:72:31`) у `text.victor_bms_mac` → блок перепідключився до неї. Повернути першу.
9. [ ] **Точка доступу:** тимчасово вимкнути домашній Wi-Fi (або прошити з неіснуючими SSID). Через ~1 хв з'являється мережа «Victor Setup», телефон відкриває сторінку вибору Wi-Fi, через неї підключаєш блок до хотспоту телефона.
10. [ ] **Збої:** вимкнути роутер на 20 хв → після ввімкнення все повернулось само. Вимкнути живлення блоку → після ввімкнення лічильники енергії не обнулились.
11. [ ] **OTA через інтернет:** `HA_PUBLIC_URL=... tools/ota-remote.sh esphome/build/victor-pi30.ota.bin`, блок оновився, `--cleanup`.
12. [ ] **Вебсторінка:** `http://<IP блоку>/` з телефона в домашній мережі, логін із secrets.

## Перед відправкою
1. [ ] `tools/build.sh victor.yaml`, прошити по USB або OTA.
2. [ ] Блок підключився до HA, `Inverter Link` = off (це нормально, SP-3200 не Modbus), BMS онлайн.
3. [ ] У `secrets.yaml` є Wi-Fi дачі, якщо відомий.
4. [ ] Повернути домашній Solar2MQTT, увімкнути BLE домашнього JK gateway.
5. [ ] Роздрукувати або переслати [інструкцію для родича](onsite-uk.md).
