# Залізо

## Що потрібно
| Деталь | Примітка |
|---|---|
| ESP32-WROOM-32U DevKit 38-pin + антена | Основна плата для дачі. Антену прикрутити **до** першого ввімкнення |
| Wemos D1 Mini ESP32 | Запасна. У `victor.yaml` змінити `board: wemos_d1_mini32` |
| RS232↔TTL на MAX3232 | Живиться від 3.3 В. MAX232 (5 В) не підходить |
| MH-MINI-360 (DC-DC) | Вхід до ~23 В, вихід виставити на **5.0 В** |
| Шматок кабелю з RJ45 | Потрібні жили пінів 1, 2, 4, 8 |
| DS18B20 + резистор 4.7 кОм | Необов'язково, температура в шафі |
| Корпус PETG | Printables 454784 (timn), отвір під SMA, вентиляція над MINI-360 |

## Розпіновка RJ45 інвертора
Гніздо засувкою донизу, контакти до себе, зліва направо 1…8. Розпіновка однакова у PowMr / Victor і у твого SP-3200 (перевірено схемою домашнього блоку).

| Пін RJ45 | Сигнал | Куди |
|---|---|---|
| 1 | TX інвертора | MAX3232, RS232-бік, вхід приймача (R1IN / «RJ45 pin 1») |
| 2 | RX інвертора | MAX3232, RS232-бік, вихід передавача (T1OUT / «RJ45 pin 2») |
| 4 | +12 В | MINI-360 IN+ |
| 8 | GND | MINI-360 IN−, GND MAX3232 (RS232-бік) |

Колір жил не головне: у T-568A і T-568B пари 1/2 різні. **Перед першим підключенням до Victor мультиметром перевір ~12 В між pin 4 і pin 8**: у деяких поколінь PowMr живлення на іншому піні.

## Бік ESP32
| ESP32 | Куди |
|---|---|
| 5V / VIN | MINI-360 OUT+ |
| GND | MINI-360 OUT−, GND MAX3232 (TTL-бік) |
| 3V3 | VCC MAX3232 |
| GPIO16 (TX) | TTL-вхід MAX3232 (DIN / T1IN, на платі буває «TXD» або «RXD») |
| GPIO17 (RX) | TTL-вихід MAX3232 (ROUT / R1OUT) |
| GPIO2 | вбудований світлодіод. Якщо на твоїй платі його немає (буває на 38-pin DevKit), постав зовнішній: GPIO2 → 330 Ом → світлодіод → GND |
| GPIO4 | DS18B20 data + 4.7 кОм до 3V3 (якщо ставиш датчик) |

Підписи TX/RX на модулях MAX3232 непослідовні. Якщо інвертор мовчить, поміняй місцями GPIO16 і GPIO17 у `substitutions` (`inverter_tx_pin`, `inverter_rx_pin`) і перепроший; дроти перепаювати не треба. Перехрещені TX/RX на 3.3 В нічого не палять.

## MINI-360
1. Подай 12 В на IN+ / IN− (будь-який блок живлення 12 В).
2. Мультиметр на OUT+ / OUT−, крути підстроювальний резистор до **5.0 В**.
3. Лише після цього підключай до ESP32.

## Складання
- Кабель RJ45 зафіксуй стяжкою або кабельним вводом, щоб у дорозі не відірвалися жили.
- Антену виведи назовні через SMA в корпусі.
- Світлодіод (GPIO2) має бути видно: отвір або прозора вставка.
- USB плати має бути доступний: це запасне живлення і прошивка.
