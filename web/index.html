3 Підключення по MQTT
Локальний MQTT (Рекомендовано) Авто-підключення до homeassistant.local:1883 або налаштування у веб-інтерфейсі
Віддалений MQTT (TLS) Хмарний брокер або віддалений сервер через захищене TLS з'єднання (порт 8883)
💡 Повна конфігурація у локальному вебінтерфейсі пристрою:
Прошитий пристрій за замовчуванням автоматично шукає брокер homeassistant.local:1883.
Якщо у вашого брокера інша IP-адреса чи потрібен пароль — після прошивки відкрийте адресу пристрою у браузері http://<ip-адреса-esp32>/. Там доступні поля введення MQTT, кнопки підключення BMS в 1 клік, струми заряду та правила!
Обрано: PowMr / Victor + JK BMS (Локальний MQTT)
Повний комплект: зчитування даних інвертора по RS232, зчитування напруг кожної комірки батареї по Bluetooth, автоматичні правила захисту акумулятора за SOC на борту ESP32, публікація даних у MQTT.
Ваш браузер не підтримує Web Serial API. Для прошивки в один клік відкрийте цю сторінку в Google Chrome або Microsoft Edge на комп'ютері чи Android-смартфоні.

Кожна прошивка містить повноцінний вбудований веб-сервер ESPHome v3. Після підключення плати до домашньої мережі вам доступна панель, де можна змінити будь-яке налаштування без перепрошивки!

Як увійти до локального вебінтерфейсу:

  1. Знайдіть IP-адресу плати в списку клієнтів вашого Wi-Fi роутера або відкрийте адресу http://solar-node.local/.
  2. Браузер запитає логін і пароль (HTTP Digest):
    Логін: admin
    Пароль: change-me (або встановлений у secrets.yaml)
  3. Перед вами відкриється сторінка з усіма сенсорами, перемикачами та налаштуваннями!

📡 1. Динамічне налаштування MQTT брокера

Поля MQTT Broker Host, MQTT Broker Port, MQTT Username, MQTT Password доступні для редагування прямо на сторінці. Введіть новий IP та натисніть кнопку MQTT Reconnect Apply — налаштування збережуться в енергонезалежну Flash-пам'ять ESP32 і пристрій миттєво перепідключиться.

🔋 2. Вибір та підключення Bluetooth BMS в 1 клік

Блок постійно сканує ефір на наявність JK, Daly або JBD BMS. У вебінтерфейсі відображаються знайдені пристрої та кнопка Connect Discovered BMS 1 або Auto-Connect Nearest BMS. Жодного ручного пошуку MAC-адрес!

⚡ 3. Керування інвертором та захистом батареї

Прямо з браузера можна змінювати максимальний струм заряду (10A..80A), пріоритет джерела живлення (Solar-Utility-Battery), перемикати заряд/розряд BMS та активувати автономні правила контролю струму за рівнем заряду SOC.

Після завершення прошивки браузер запропонує ввести ім'я та пароль вашого Wi-Fi.
