Solar & BMS Gateway Installer

Інтерактивний майстер вибору та прошивки ESP32 прямо з браузера

1 Який у вас інвертор?
PowMr / Victor / SmartESS Modbus RTU 2341 (POW-HVM, NM-ECO PLUS, EASun)
Voltronic / Axpert / EASun Протокол PI30 / Q-команди (SP-3200, MPP Solar)
2 Чи підключена батарея з BMS?
Так, JK BMS (Bluetooth BLE) JK-B1A..., JK-B2A... (45+ сенсорів, напруги комірок, балансир)
Ні, BMS немає Тільки моніторинг інвертора (легша прошивка без Bluetooth)
3 Як підключатимете до Home Assistant?
Home Assistant API (Рекомендовано) Пряме підключення в локальній мережі або через VPN, без MQTT
MQTT Брокер Для віддаленого моніторингу через інтернет або хмарні мости
Обрано: PowMr / Victor + JK BMS (Home Assistant API)
Повний комплект: зчитування даних інвертора по RS232, зчитування напруг кожної комірки батареї по Bluetooth, автоматичні правила захисту акумулятора за SOC на борту ESP32, миттєве автовиявлення в Home Assistant.
Ваш браузер не підтримує Web Serial API. Для прошивки в один клік відкрийте цю сторінку в Google Chrome або Microsoft Edge на комп'ютері чи Android-смартфоні.

Після завершення прошивки браузер запропонує ввести ім'я та пароль вашого Wi-Fi.

Вихідний код проєкту доступний на GitHub.
