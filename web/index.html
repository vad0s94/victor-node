Solar & BMS Gateway Installer

Інтерактивний майстер вибору та прошивки ESP32 прямо з браузера

1 Який у вас інвертор?
PowMr / Victor / SmartESS Modbus RTU 2341 (POW-HVM, NM-ECO PLUS, EASun)
Voltronic / Axpert / EASun Протокол PI30 / Q-команди (SP-3200, MPP Solar)
2 Акумулятор та тип BMS
JK BMS (BLE) Повний моніторинг кожної комірки (1..16S/24S), балансир по BLE
Daly Smart BMS (BLE) Daly Smart BMS (Blue/standard), напруги, струм, температури
JBD / Xiaoxiang (BLE) Liontron, Overkill Solar, JBD BLE (комірки, ключі, SoC)
Без BMS (тільки інвертор) Легка прошивка без Bluetooth для моніторингу інвертора
🔍 Пошук Bluetooth BMS в ефірі Новинка

Після прошивки ESP32 сам сканує BLE-ефір і дозволяє підключити знайдену BMS в 1 клік у веб-інтерфейсі чи Home Assistant. Ви також можете перевірити наявність сигналу вашої батареї прямо зараз у браузері:

3 Підключення по MQTT
Локальний MQTT (Рекомендовано) Локальний Mosquitto / EMQX брокер у вашій мережі (порт 1883)
Віддалений MQTT (TLS) Хмарний брокер або віддалений сервер через захищене TLS з'єднання (порт 8883)
Обрано: PowMr / Victor + JK BMS (Локальний MQTT)
Повний комплект: зчитування даних інвертора по RS232, зчитування напруг кожної комірки батареї по Bluetooth, автоматичні правила захисту акумулятора за SOC на борту ESP32, публікація даних у MQTT.
Ваш браузер не підтримує Web Serial API. Для прошивки в один клік відкрийте цю сторінку в Google Chrome або Microsoft Edge на комп'ютері чи Android-смартфоні.

Після завершення прошивки браузер запропонує ввести ім'я та пароль вашого Wi-Fi.
